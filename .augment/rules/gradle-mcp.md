# Gradle MCP Rule

## Purpose

Always use gradle-mcp when needing to run Gradle tasks (build, test, assemble, clean, etc.) for Android projects.

## When to Use


- Building Android applications and libraries
- Running unit tests and integration tests
- Generating APKs and bundles
- Dependency management and resolution
- Build configuration and optimization
- CI/CD pipeline integration

## Best Practices


- Use gradle-mcp for all Gradle-related operations
- Ensure proper error handling and fallback mechanisms
- Monitor build performance and optimization opportunities
