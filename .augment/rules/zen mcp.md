# Zen MCP Enhanced Rule

## Core Usage
- Always use zen mcp for context retrieval
- Always use zen mcp for complex problems requiring deep thinking and planning

## Multi-AI Integration
- **MANDATORY**: For all critical decisions, trigger multi-AI consultation (see `multi-ai-consultation.md`)
- **AUTOMATIC**: Consult all available models (Gemini, GPT, Grok) for:
  - Architecture reviews and refactoring plans
  - Security-critical implementations
  - Performance optimization strategies
  - Major technology decisions

## Enhanced Workflow
1. **Initial Analysis**: Use zen mcp for deep thinking and planning
2. **Multi-AI Review**: Automatically trigger multi-AI consultation for validation
3. **Consensus Synthesis**: Combine insights from all models
4. **Final Recommendations**: Provide comprehensive, multi-validated guidance

## Integration Points
- **Architecture Rule**: Enhanced with multi-AI validation
- **Gradle MCP Rule**: Includes AI consultation for build decisions
- **Android MCP Rule**: Multi-AI review for Android-specific choices
- **Multi-AI Consultation Rule**: Primary orchestration rule

## Quality Assurance
- Minimum 2 models must respond for critical decisions
- Consensus threshold of 70% for major recommendations
- Automatic fallback if primary models unavailable
- Comprehensive analysis reports with all perspectives
